# Hospital Readmission Dashboard

Live dashboard: https://public.tableau.com/app/profile/ikenna.nwogu/viz/CanadianHospitalReadmission/CANADIANHOSPITALREADMISSION

Built in Tableau Public using cihi_hospital_clean.csv.

## Views Included

| View | Description |
|------|-------------|
| Readmission Rate by Province | Bar chart ranking all 10 provinces — Atlantic provinces visibly above national average |
| Year-over-Year Trend | Line chart 2018–2022 with COVID-19 spike annotated in 2020 |
| Diagnosis Comparison Heat Map | Province × diagnosis matrix showing which combinations carry the highest rates |
| Geographic Distribution | Provincial map with readmission rate encoded by colour intensity |

## Key Visual Findings
- NL, NS, and NB are clearly separated from the national average on the provincial bar chart
- COPD and Heart Failure cells are the darkest on the heat map across all provinces
- The 2020 trend line spike is visible but shows near-full recovery by 2022
- Atlantic provinces show consistently darker shading on the geographic map
